# 🇮🇳 Bharat Intelligence

### AI-Powered Citizen Intelligence & Governance Platform

Bharat Intelligence is an intelligent governance platform designed to bridge the gap between citizens and government authorities through AI-driven insights, grievance management, scheme discovery, trend analysis, and data-powered decision making.

The platform empowers both citizens and officials with real-time information, complaint tracking, policy awareness, and analytical tools to improve governance efficiency and public engagement.

---

## 🚀 Problem Statement

Citizens often struggle to:

* Track grievances effectively
* Access government schemes
* Understand policy updates
* Report local issues efficiently
* Receive timely responses from authorities

Government officials face challenges in:

* Managing large volumes of citizen complaints
* Identifying emerging trends
* Prioritizing critical issues
* Monitoring regional concerns
* Making data-driven decisions

Bharat Intelligence aims to solve these challenges through a unified AI-powered platform.

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/Devengoyal885/Bharat-Intelligence.git
```

Navigate into the project

```bash
cd Bharat-Intelligence
```

Install dependencies

```bash
npm install
```

Run locally

```bash
npm run dev
```

Open

```text
http://localhost:3000
```
